# 캐릭터 아트 바이블 — 마을 주민 동물 6종

유니코 팜 3D 판의 마을 주민은 두 발로 서는 꼬마 동물이다. 주인공·다른 접속자·KOAT 체험관 담당·안내데스크는 **유니코(유니콘)** 그대로다.
이 문서는 새 주민·새 옷·새 표정을 만들 때 지킬 규칙과 숫자를 모은다. 코드 위치는 `docs/GAME_DESIGN.md` §6.

- 런타임 표(색·얼굴 부품·옷·움직임·대사): `src/game/species.js`
- 모양(SDF)·칠하기·얼굴/옷 기준점(굽기 전용): `scripts/lib/species_shapes.mjs`
- 3D 조립·움직임: `src/game/unico.js` (`buildSpeciesTemplate`, `_speciesSecondary`, `_express`)
- 2D 초상화: `src/ui/portrait_species.js` (+ 공통 부품 `src/ui/portrait_parts.js`)
- 미리보기: `npm run dev` → `/unico_preview.html?species=fox,cat&view=side&expr=happy&pose=walk` · `?portraits=1`

## 2. 규칙 12개

1. **히어로 특징 하나**를 실제 비율의 1.5배 이상 과장. 기본 따라가기 카메라(9m, 피치 0.45, 시야 45°)에서 48–64px 실루엣으로 구분돼야 한다. 모바일 18m 에서 주민 키는 약 50–75px.
2. **밝기 사다리**: 곰 0.06 < 너구리 0.27 < 여우 0.34 < 고양이 0.38 < 토끼 0.53 < 강아지 0.66 < 유니코 1.0. (토끼 밀크티를 조금 회색 쪽 `#DDBBA0` 으로 — 저해상도·먼 화면에서 강아지 비스킷과 같은 연베이지로 보이지 않게) 순백(`#FFFFFF`) 몸은 유니코 전용. 같은 밝기대는 귀·꼬리 모양으로 구분(색맹 대비).
3. 주민에게 **뿔·갈기 금지** (뿔은 유니코 브랜드 표식). 발굽 슬롯(hoof)은 발바닥·양말·장갑으로 쓴다.
4. **얼굴 가족**: 큰 광택 검은 눈(하이라이트 2개, 강아지·토끼는 3개), 분홍 볼, 가는 입선을 모두 공유. 종 차이는 코·입·눈썹·눈 위치·홍채(고양이만)로만.
5. **옷은 히어로 특징과 그 표식을 가리지 않는다.** 모자는 귀가 앞으로/뚫고 보이게, 고글은 이마 위. 앞치마·실험복·조끼 금지(턱받이·가면·반달·줄무늬를 가림). 옷 강조색 = 역할색.
6. **옆에서 뿔처럼 보이는 귀 금지**: 뾰족 귀(여우·고양이)는 판 두께 배율 ≥ 0.55, 귀 면을 바깥으로 0.45rad 돌리고, 귀 안쪽 색을 앞면에 칠한다. 토끼 긴 귀도 같은 규칙(판 0.75, 바깥으로 0.5rad). 옆모습 캡처 필수 + 테스트(귀 70% 높이 옆 폭 여우·고양이 ≥ 0.09m, 토끼 선 귀 ≥ 0.08m).
7. **얇은 부위 두께**: 원본(step 0.03)에서 귀 끝 반두께 ≥ 0.0175m, 꼬리 반지름 ≥ 0.045. LOD 굽기에서만 귀·꼬리 뼈 프리미티브를 +0.012m 두껍게.
8. **늘어진 귀·긴 귀는 뿌리를 빼고 머리에서 2셀(0.06m) 이상 떨어뜨린다** (스킨이 머리로 번지지 않게).
9. **가짜 AO**(종만): 정점 색 × (0.82 + 0.18·smoothstep(−0.6, 0.6, 법선 y)). **또렷한 표식 경계**(종만): 색 슬롯 가중치를 2.2 제곱해 다시 정규화 → 가면·눈가 패치·턱받이 가장자리가 번진 얼룩처럼 보이지 않음(용량 0, 유니콘은 그대로).
10. 대사·주석·문자열은 한국어. 다른 상업 게임 이름·동요 가사 인용 금지(원작 대사만).
11. 모든 주민은 가슴(또는 스카프 매듭·멜빵 앞판)에 작은 **KOAT 새싹 브로치**.
12. **표정 상태**: 기본 / 말하기(입 8Hz) / 행복(^^ 눈) / 놀람(눈 1.15배) / 생각(눈 위로). 곰은 대기 중 70% 눈웃음 — **눈만** ^^, 입은 다문 순한 호.
    입을 벌리는 때는 말하기·만세(cheer)·하트·강아지 반가운 꼬리(wag)·선물 직후·하품뿐. 세수·허리 두드리기·앞발 비비기는 눈웃음 + 다문 입. 벌린 입일 때 닫힌 입 선은 그리지 않는다(같은 얼굴 메시에서 그릴 범위만 바꿈).

## 4. 리그와 공통 몸

단위 m, 발바닥 y=0, 정면 +Z. 몸통 뼈 B(0, 0.38, 0), 머리 H = (0, 1.30, 0.04), 꼬리 뿌리 T = (0, 0.42, −0.25).
뼈 순서(스킨 인덱스, 바꾸지 않음): `body, head, legL, legR, armL, armR, tail, tail2, tail3, earL, earR, (earL2, earR2 — 토끼만)`.
어깨→손 벡터는 모든 종이 같다 → 유니코의 모든 두 발 포즈·손 도구가 그대로 맞는다(곰만 armX 0.31).
그래서 팔을 들어 올리는 데 한계가 있다: 손 인사·만세에서 팔 z 회전이 약 2.05rad 를 넘으면 손이 큰 머리 안·뒤로 들어가 볼에 손을 댄 '으쓱'처럼 보인다. 짧은 팔로 손이 머리 타원 밖에 오는 가장 높은 곳은 어깨에서 약 40° 위.
주민 만세는 **옆으로 크게 벌린 V**: 팔 (x 0.15, z ±1.8) → 손 약 x ±0.56·y 1.05·조금 앞 (머리 타원 거리 1.4 이상 — 테스트가 지킴). 손 인사는 1.9±0.16 (머리 옆).

**몸통은 종마다 폭·배만 다르게** (팔 벡터는 그대로) — 목 아래가 다 같아 보이지 않게:

| 여우 | 0.25 / 0.115 | 0.9 | 0.22 / 0.05 | 0.105 → 0.085 | 가는 발목 |

배를 내밀면 배 칠하기(턱받이·배 무늬) 타원도 앞으로 옮겨야 표면에 닿는다 (너구리 z 0.28, 토끼 z 0.26).

**토끼 귀 (스펙 §4.6 과 다른 아트 결정)**: 두 귀 모두 판 두께 0.75·귀 면을 바깥으로 0.5rad (옆에서 2–3px 가시·부리처럼 보이던 얇은 판을 넓힘). 접힌 왼쪽 끝은 윗마디 0.34m 를 mid 에서 mid + 0.34·normalize(−0.7, −0.5, 0.45) — 바깥·아래·조금 앞으로 머리 옆에 늘어진 롭이어(뭉툭한 엄지·짧은 그루터기처럼 안 보이게). 넓힘 타원·판 법선·귀 안 칠하기도 같은 회전, 리본은 earL 뼈 그대로.

### 4.1 옷 만들기

- **천은 납작한 띠**(`bandGeo`): 둥근 관(튜브)은 부풀린 고리·목베개처럼 보인다. 단면은 둥근 사각, 표면 법선 쪽으로 얇게 — 스카프 높이 0.055 × 두께 0.022, 전대 0.06 × 0.018, 머리띠 0.055 × 0.02, 멜빵 끈 0.04 × 0.012, 고글 끈 0.034 × 0.012. 고리 점과 그 점의 표면 법선(`rings.*.ns`, `paths.*N`)은 bin 의 meta 에 굽는다.
- 고리는 몸에 붙인다: 띄움 0.006–0.01 (스카프·전대). 전대는 턱받이 바로 아래(y 0.53)에서 앞쪽을 0.02 늘어뜨림(dip). 고글 끈은 이마 앵커와 뒤통수(머리 중심 + 0.12)를 지나는 기울어진 평면에서 두개골 표면을 따라감(24점) — 떠 있는 보라 고리 금지.
- 거칠기는 정점마다(`rough` 속성, 재질 하나): 천 0.85, 코·단추·금속 0.38, 그 밖 0.6 — 반들반들한 띠가 비닐처럼 보이지 않게.
- 매듭: 스카프는 큰 삼각 + 0.4rad 돌린 작은 삼각(턱받이 위쪽에 겹침), 여우 머리띠 매듭은 +x 쪽 관자놀이(머리띠 고리 점 3 — 정면에서 화면 오른쪽, 초상화와 같은 쪽) + 짧은 끈 두 가닥, 곰 머릿수건 매듭은 오른쪽(+x) 뒤 단(귀 뒤, 방위 2.05rad) + 아래로 늘어진 끈 두 가닥 — 옆·¾ 에서 보임.
- 곰 머릿수건(얇은 천): 정수리~뒤통수만 덮는 낮은 덮개(구 위 0.40π)를 머리 + 0.015 로, 중심 (0, 0.06, −0.04)·뒤로 0.25rad — 앞 단이 이마 위라 단과 눈썹 사이로 털이 보임. **귀 자리는 천을 머리 속으로 눌러 구멍**(귀 뼈 0.15m 안, 최대 6cm) → 귀가 천을 뚫고 다 보임. 가는 말림 단(관 0.008, 천 색) — 굵은 테는 딱딱한 헬멧·버섯 갓처럼 보여서 뺐다. 연한 잔꽃 점(r 0.016) 18개, 뒤로 목덜미까지 늘어진 납작한 삼각 자락(r 0.12, 길이 0.18).
- 곰 몸빼: 엉덩이 고리 + 가랑이·엉덩이 덮개(몸통 뼈 납작 공, 루트 (0, 0.3, −0.01) r 0.17 × [1.3, 0.85, 1.6] — 앞뒤로 길고 옆으로 좁게) + 다리 뼈 바짓가랑이. **바짓가랑이는 몸에 맞춤**: 굽기 때 다리 축에서 높이 9곳 × 16방향으로 몸 표면까지 거리를 meta(`limbs.leg.fit`)에 넣고, 런타임은 그 거리 + 틈(0.02, 아래는 0.014)과 기본 둘레(0.15 → 발목 0.104) 중 큰 값 — 두 다리가 한 풍선으로 붙지 않으면서 털이 바지를 뚫지 않음(테스트: 바깥쪽 정점 95% 이상이 몸 밖). 안쪽(다른 다리 쪽)은 가랑이(y 0.2) 위에서는 가운데 선을 조금 넘어(x −0.025) 두 바짓가랑이가 겹치고(뒤에서 털이 검은 세로 줄로 보이지 않게), 아래는 기본 둘레. 허리 고무줄은 표면에서 0.008(관 0.02). 짧은 꼬리는 몸빼를 입은 동안 숨김(꼬리 뼈 크기 0.001). 컬링 구는 몸과 같은 ×1.45.
- 곰 반달: 큰 머리 아래로 내려 중심 y 0.76, 바깥 타원 [0.29, 0.15, 0.25]에서 위로 0.055 옮긴 같은 타원을 빼서 약 6cm 띠 + 양 끝에 위로 솟은 뿔(캡슐 x ±0.2→±0.25, y 0.69→0.79) — 목둘레 흰 깃·털 칼라처럼 보이지 않는 V 초승달.
- 토끼 앞니: 0.030 × 0.045 두 개(간격 ±0.016)를 입선 아래 0.012·바깥 0.004 에, 뒤에 입선 색 판(0.07 × 0.051)을 대어 흰 주둥이 위에서도 테두리가 보임.
- 고양이 밀짚모자: 챙 r 0.40·크라운 뒤로 0.14·젖힘 −0.5rad → 챙이 뾰족 귀 뒤의 후광처럼 (귀와 섞여 가시 왕관처럼 보이지 않게).
- 토끼 멜빵: 앞판 가장자리에 단(관 0.012, 조금 진한 분홍), 끈은 등(y 0.66)에서 엇갈려 반대쪽 솜꼬리 위에서 끝남. 왼쪽 끈은 0.008 더 띄워 엇갈리는 곳이 겹치지 않게.
- 여우 동전 주머니: 납작한 상자(포스트잇처럼 보임) 대신 끈을 졸라맨 둥근 복주머니(공 r 0.06 × [1, 0.9, 0.7] + 끈 고리 + 금 똑딱이).
- 고양이 눈: **호박색은 눈 안에** — 검은 눈 r 0.08(앞으로 0.5 볼록), 그 앞면보다 0.004 앞에 호박색 홍채 원판 r 0.068(납작 0.3) → 검은 테두리 약 1cm, 그 앞에 세로로 긴 검은 동공 r 0.045 × [0.62, 1, 0.3], 맨 앞 반짝임. 눈 밖 넓은 호박색 띠는 금테 안경·부엉이 눈처럼 보이고 곰 안경과 겹쳐서 뺐다(초상화와 같은 눈).

**큰 꼬리는 쉬는 각도로 몸 옆에**: 주민은 늘 플레이어(카메라)를 마주 보므로 등 뒤 꼬리는 게임 화면에 안 보인다. 여우 붓꼬리는 뿌리 yaw 0.7·위로 0.25(흰 끝이 정면에서 목·어깨 옆으로), 고양이 물음표 꼬리는 yaw 0.8·둘째 마디 −0.2(고리가 오른팔 옆으로). 쉬는 각도는 꼬리 전체를 통째로 돌리고(다음 마디는 움직임만 따라감), 걸을 때는 반만. 쓸기·물결은 그 둘레로.

반응: 플레이어가 5m 안이면 attention ↑ → 귀 쫑긋. 강아지는 4m 안에 처음 들어오면 갸웃, 반가우면 꼬리를 세게 흔듦. 여우는 우정 3하트 이상이면 꼬리 흔들며 손 인사. 고양이는 우정 3하트 이상·바라볼 때 느린 눈인사. 놀람(트랙터)은 종마다 귀·꼬리 부풀기와 한마디.
이름표 높이 = max(2.0, 키 × 배율 + 0.28), 감정 아이콘 +0.30, 말풍선 +0.70.

## 6. 2D 초상화

200×200 SVG, 머리 중심 ≈ (100, 106), 윤곽선 `#5B4434` 불투명 0.45 굵기 2.6, 단색 채움 + 그늘 하나 + 볼 홍조. 대화창에서 64–112px 로 보이므로 표식·선은 굵게.
- 3D 와 같은 표식·옷(줄인 옷 규칙 그대로). 토끼의 접힌 귀는 3D 와 같은 쪽(정면에서 볼 때 화면 왼쪽).
- 감정: heart·cheer = ^^ 눈 + 볼 진하게, think = 눈썹 기울임·눈 위로·턱 괴기, startle = 큰 눈 + 땀방울, wave = 든 손, 그 외 = 역할 기본(여우 동전, 너구리 태블릿, 강아지 확성기, 곰 미소, 고양이 낚싯대 끝, 토끼 만세). 곰은 놀람·생각 말고는 늘 눈웃음.
- 클래스: 눈 `p2-eye`(깜빡임), 입 `p2-mc`/`p2-mo`(말할 때 번갈아), 귀 `p2-ear`(뿌리 기준 살랑), 토끼 코 `p2-nose`(씰룩). 귀·코 애니메이션 CSS 는 SVG 안 `<style>` 에 있고, 움직임 줄이기 설정이면 멈춘다.

## 7. 64px 실루엣 시험

1. `/unico_preview.html?species=fox,raccoon,puppy,bear,cat,rabbit&unicorn=1&view=front`(그리고 `side`, `back`, `three`)를 캡처.
2. 이미지를 흑백 이진화(배경 제외)해 캐릭터마다 키 64px 로 줄인 실루엣 시트를 만든다 (유니코·콩이 포함).
3. 이름을 가리고 봤을 때 8개 모두 구분되면 통과. 옆모습에서 뾰족 귀가 뿔처럼 보이면 실패(규칙 6).
4. 게임 안에서도: 9m 따라가기 카메라·모바일 18m 에서 주민 키 픽셀을 재고, 걷기 한 주기(8프레임)로 귀·꼬리 뿌리가 늘어나지 않는지 본다.

## 8. 굽기와 검사

```
npm run models:unico                                   # 주민 원본·LOD 12개만 (모양을 고친 종만 바이트가 바뀜)
node scripts/build-unico-mesh.mjs --only=v_fox,v_fox_lod # 한 종만
node scripts/build-unico-mesh.mjs --unicorn             # 유니콘 bin 4개 (유니콘 모양을 고쳤을 때만 — 기본으로는 굽지 않음)
node --test tests/species.test.js tests/unc2.test.js      # 모양 해시·실루엣·뿔 방지·LOD·귀 소유·슬롯 비율·앵커·그리기 수·예산·초상화
```
- 유니콘 4개는 예전 v1 bin 을 제자리 변환한 것(모양 0 변화)이라 다시 굽지 않는다: 다시 구우면 모양은 같아도 바이트가 바뀌어 모델 캐시 주소(?v=내용 해시)가 바뀌고 모든 플레이어가 약 270KB 를 다시 받는다.
- 모양(`species_shapes.mjs`)을 고치면 반드시 다시 굽는다 — bin 헤더의 모양 해시가 다르면 테스트가 실패한다.
- 예산(gzip 9, 지금 굽기 +약 5%): 주민 bin 12개 ≤ 560KB(지금 532KB), 첫 화면 캐릭터 묶음 ≤ 480KB(456KB), 캐릭터 bin 전체 ≤ 840KB(802KB). 넘으면 (1) 원본 step 0.030 → 0.032, (2) LOD 법선 빼기 순서로 줄인다.
- 옷 고리(허리띠·스카프·몸빼)는 몸통·머리·다리만으로 계산한다(꼬리·팔을 감싸 훌라후프가 되지 않게 — 테스트가 지킴).
- 슬롯 비율 기준값은 승인한 굽기의 약 90%: 곰 반달은 앞면만 가는 초승달이 되어 1.08% → 기준 0.95%.
- 노드 실루엣 시트(스킨 적용, 정면·옆·뒤 + 64px): 브라우저 없이 꼬리·귀가 정면에서 보이는지 먼저 확인할 때 씀 — 정사영으로 스킨 정점을 래스터화.
