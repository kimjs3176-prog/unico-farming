# 경제 밸런스 점검

`node scripts/balance.mjs` 결과 (vendored skill `claude-code-game-studios/balance-check` 절차: 유입 지도 → 지배 전략 → 차익 루프 → 진행 속도).

## 조정 이력

| 문제 | 근거 | 조치 |
|---|---|---|
| 쌀 ★5 가 분당 321로 최고 작물(62)의 5배 — 지배 전략 | 논 6칸만 돌려도 다른 시스템이 무의미 | 쌀 단가 110 → 50. 보통 관리(★3) ≈ 최고 작물, 숙련 관리(★5) ≈ 2.2배로 노력 보상 |
| 달걀 분당 5 — 쓸모없는 선택지 | 사료 15 대비 수익 5 | 달걀 20 → 30 |
| 양배추(20)·옥수수(26.7)가 하위 작물보다 낮음 | 해금할수록 손해 | 양배추 수확 1→2, 옥수수 55→75·수확 2→3. 해금 순서대로 48→52→55→62→65 |
| 한 시간 남짓이면 살 것이 없음 (기존 소비처 47,040 코인 = 30% 효율로 2.2시간) | 코인이 첫 한두 시간 뒤 의미를 잃음 | 수익을 늘리지 않는 꾸밈 소비처 추가: 집 벽지·바닥 16가지·가구 11가지, 특별 소품 12가지(Lv5~8), 날마다 바뀌는 오늘의 특별 상품(한정 소품·색 바꾼 옷), 마을 건물 ★2·★3 등급(효과는 조금만: 직판장 최대 ×1.15, 방앗간·온실 그대로). 합계 172,015 코인 → 8.2시간 |
