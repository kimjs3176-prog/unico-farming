# 유니코 팜 접근성 점검

기준: **WCAG 2.1 AA** (+ WCAG 2.2 SC 2.5.8 터치 대상 최소 크기). AAA 항목은 '권장'으로만 다루고 실패로 치지 않는다.
원본: [Claude-Code-Game-Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) `agents/accessibility-specialist.md` (MIT) 의
기준·점검표·결과 형식을 이 프로젝트(바닐라 three.js + DOM UI, 한국어, 모바일 터치)에 맞게 옮김. 엔진·게임패드 항목은 뺌.

## 1. 자동 점검 (먼저)

```bash
npm run dev                                   # 다른 터미널
npm run a11y                                  # = node scripts/a11y-check.mjs http://localhost:5173/
node scripts/a11y-check.mjs http://localhost:5173/ --out docs/a11y/$(date +%F).md   # 보고서 저장
```
Playwright 가 필요하다(저장소 의존성에는 없음): `npm i -D playwright && npx playwright install chromium`, 또는 전역 설치.

PC(1280×800)·폰(390×844, 터치)에서 HUD·☰ 메뉴·장터·가방·퀘스트·도감·환경설정·도움말·대화(선택지)를 열고 잰다.

| 항목 | 기준 | 등급 |
|---|---|---|
| 글자 명암 대비 | SC 1.4.3 — 보통 글자 4.5:1, 큰 글자(24px↑ 또는 굵게 18.66px↑, Jua 글꼴은 굵게 취급) 3:1. 그라데이션 배경은 **가장 나쁜 색 멈춤점** 기준 | 필수 |
| 폰 터치 대상 24px 이상 | SC 2.5.8 (WCAG 2.2 AA) | 필수 |
| 버튼 이름 | SC 4.1.2 — 아이콘만 보이는 버튼은 `aria-label`/`title` | 필수 |
| 폰 터치 대상 44px | SC 2.5.5 (AAA) | 권장 |
| 작은 글자 (폰 11px·PC 12px 미만) | 게임 권장 | 권장 |
| 움직임 줄이기 | SC 2.3.3 (AAA) — `prefers-reduced-motion` | 권장 |

**판단 불가는 통과가 아니다.** 3D 장면 바로 위 글자(배경을 잴 수 없음)와 색만으로 전달하는 정보는 자동으로 알 수 없으니
보고서의 '판단 불가' 줄을 그대로 남기고, 아래 수동 점검으로 확인한다.

## 2. 수동 점검표 (자동으로 못 보는 것)

화면마다 스크린샷(폰·PC)을 찍어 보고 확인:
- [ ] **색만으로 전달하지 않음** (SC 1.4.1): 작물 상태(물 부족·다 익음), 동물 기분, 시세 오름/내림, 미니게임 초록 구간, 논 물 높이 → 아이콘·글자·모양이 함께 있나
- [ ] **3D 화면 위 글자**: 이름표·말풍선·떠오르는 숫자·안내(`.prompt`)가 밝은 하늘·눈 덮인 땅·밤 장면에서도 읽히나 (그림자/테두리/배경판)
- [ ] **소리만으로 전달하지 않음**: 입질(낚시)·불청객 등장·과열(탈곡) 같은 소리 신호에 화면 표시도 있나
- [ ] **시간 제한** (SC 2.2.1): 미니게임 외 일상 진행에 시간 압박이 없나, 대화가 저절로 넘어가는 건 오토플레이 중일 때만인가
- [ ] **한 손가락으로 가능** (SC 2.5.1): 두 손가락 줌·드래그 말고도 같은 일을 할 방법이 있나
- [ ] **글자 크기 설정**(환경설정 보통·크게·아주 크게)에서 잘리거나 겹치는 UI 가 없나 — `아주 크게` 로 자동 점검을 한 번 더
- [ ] **키보드만으로**: 창 닫기(Esc), 선택지(숫자 키), 주요 메뉴(I·Q·M·P), 포커스 테두리 보임
- [ ] **움직임**: 화면 흔들림·반짝임이 '동작 줄이기' 설정에서 꺼지나 (`src/game/juice.js` 는 꺼짐)

## 3. 결과 형식

```
## 접근성 점검: [화면/기능] — [날짜]
| 발견 | WCAG 기준 | 심각도 | 등급 | 고치는 법 |
|---|---|---|---|---|
| 장터 '사기' 버튼 흰 글자 2.5:1 | SC 1.4.3 Contrast (Minimum) | S2 높음 | 필수 | 흰 글자용 청록(--teal-t-*) 사용 |
| 시세 오름/내림을 색으로만 | SC 1.4.1 Use of Color | S3 보통 | 필수 | ▲▼ 기호 함께 |
```
- 심각도: S1 치명(진행 불가) · S2 높음 · S3 보통 · S4 낮음 — 영향받는 플레이어 기준
- 등급: **필수**(AA 기준 실패, 또는 게임에 중요한 정보가 한 가지 감각으로만) / **권장** / **판단 불가 — [못 본 이유]**
- 보고서는 `docs/a11y/YYYY-MM-DD.md` 에 저장. 필수 0건이 아니면 그 UI 작업은 끝난 것이 아님

## 4. 고칠 때 쓰는 것
- 색 대비 계산: `src/ui/contrast.js` (`contrast(a, b)`, `textOn(bg)` — 흰 글자/진한 갈색 중 잘 읽히는 쪽). 테스트 `tests/contrast.test.js`
- 흰 글자가 올라가는 청록은 `--teal-t-hi/--teal-t/--teal-t-d` (`src/ui/theme.css` 맨 아래). 장식용 `--teal` 은 그대로 둬도 됨
- 대화 이름표·선택지 번호 글자색은 `--dlg-on` 이 배경색에 맞춰 자동. 새 인물 색을 넣으면 `tests/contrast.test.js` 목록에 추가
- 아이콘만 보이는 버튼은 만들 때 `setAttribute('aria-label', …)`
- 도트 판(`pixel.html`)은 캔버스 UI 라 이 스크립트 대상이 아님 → 수동 점검표만
