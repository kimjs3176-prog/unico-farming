# 엔진 조립

코드 예시는 three.js; 다른 엔진에서도 규칙은 같다.

> 유니코 팜: 캐릭터는 GLB 가 아니라 미리 구운 UNC2 bin(`public/models/villager_<종>.bin`, `unico_*.bin`)을 `src/game/unico_mesh.js` 가 읽고, 조립은 `src/game/unico.js` 가 한다. 아래의 "필수 가중치가 없으면 알기 쉬운 오류로 멈춘다", "변형은 모든 패스에", "검사 시트" 원칙은 그대로 적용된다.

## 모델 로드

`.glb` 는 표준 로더로 읽는다. 호스팅이 `.glb` 를 주지 않으면 `export_model(out, as_json=True)` 로 내보내고 `GLTFLoader.parseAsync` 전에 base64 를 푼다. 모델은 새것인데 캐시가 옛것이면 주소에 버전을 붙인다.

로드가 실패하면 장면은 이유를 보여 주고 블록아웃으로 돌아간다. 쓰러지지 않는다. 필수 변형 가중치가 없거나, 숫자가 아니거나, 전부 0 이면 조립이 알기 쉬운 오류로 멈춘다(`motion_kit.js` 의 `prepareClothGeometry`, `makeClothChain`): 조용히 채운 0 은 "작동은 하지만" 움직이지 않는 천을 만든다.

## 리그

모델에 따라 둘 중 하나:

- **단단한 부품** (스크립트 모델): 움직이는 부품마다 관절에 중심을 둔 자기 노드, 리그 뼈에 건다(부품 위치 빼기 관절 위치). 리그 트리:
  ```
  root (위치, 방향)
  └─ hips (눌림, 걸음 때 들림)
     └─ body (숙임, 기울기, 흔들림)
        ├─ head (시선, 회전 앞서기) → 머리쓰개, 얼굴
        ├─ arm L/R: 어깨 → 팔꿈치 → 손 → 손에 든 물건
        └─ 옷, 매달린 것
  root → 발 (hips 아래가 아니라 root 공간에서 계획)
  ```
- **한 덩어리 메시** (image-to-3D, 스컬프트, 유니코 팜 SDF): 옷에 가려진 관절에서 부품으로 자르거나 스키닝한다(Rigify, 자동 가중치, Mixamo; 유니코 팜은 SIGMA 경계 가중치). 천 변형 가중치는 정점 속성으로 쓴다(`blender_kit.py` 의 `set_weight_attribute`).

손에 든 물건은 쥔 포즈로 손에 붙인다.

## 겉모습

- 재질 이름으로 칠하기: 색은 계약서 팔레트에서 가져온다. 그래야 새 모델 없이 다시 칠할 수 있다.
- **변형은 모든 패스에.** 셰이더 변형(천 흔들림, 옷자락)은 기본 재질, 외곽선, 있으면 법선 패스, 그림자 깊이 재질에 똑같이 넣는다. 아니면 외곽선이나 그림자가 천보다 늦는다. 삽입문을 돌려주는 함수 하나를 두고 어디서나 연결한다.
- 화면 공간 잉크나 법선 외곽선 스타일이면: 어두운 구멍(얼굴 구멍, 안감)은 잉크 패스에서 가리고, 효과(먼지, 빛, 스프라이트)는 그 밖에 둔다. 아니면 구멍 안에 거미줄 같은 선이 생긴다.
- 옆에서 얼굴 구멍으로 보이는 다른 것은 모델에서 어둡게 하거나 없앤다. 양쪽 3/4 에서 확인한다.

## 검사 시트

한 번에 찍는다:
- 한 바퀴 각도, 위에서, 뒤 위에서;
- 좌우 3/4 얼굴 근접, 물건을 든 손;
- 실제 배경 위 게임 크기;
- 극단을 동시에: 고개 돌리기, 흔들림, 점프;
- 강제 굽힘: 변형 30°, 천이 눈에 띄게 휜다.

찾을 것:
- **흑백 점** — 사라진 삼각형, 보통 셰이더 가중치의 NaN;
- **천 사이로 배경이 비침** — 구멍이나 뒤집힌 면;
- **깜빡임** — 겹친 표면;
- **이음새의 어두운 틈** — 외곽선이 옆 부품을 뚫고 나옴;
- **얼굴 구멍 속 다른 것**과 **구멍 안의 잉크 선**.

어느 부품이 결함인지 찾으려면 카메라를 스냅샷처럼 놓고 모든 메시 정점을 투영해 결함 픽셀에 가장 가까운 것을 고른다. 부품을 하나씩 숨기는 것보다 빠르다.
