## 함정

1. **glTF 내보내기는 어떤 재질도 읽지 않는 UV 세트를 버린다.** 변형 가중치는 정점 속성 `_name` (POINT, FLOAT)에 두고 `export_attributes=True` 로 내보낸다. GLB 의 JSON 머리말에서 이름을 확인한다.
2. **결과 대신 입력으로 측정.** uniform 값이 아니라 셰이더 뒤 변형을 잰다.
3. **가중치의 NaN.** w 가 1 을 조금 넘을 때 `pow(1 − w, n)` 은 NaN, 삼각형이 사라진다. 가중치를 [0, 1] 로 자른다.
4. **물건을 든 손이 쥔 것을 놓친다** 전력질주나 점프에서, 그러면 물건이 휘청인다. 모든 상태에서 쥔 포즈를 지킨다.
5. **캡처가 상태를 건드린다.** 스냅샷 도우미가 모드와 카메라를 바꾸는데, `await` 사이에 메인 루프가 카메라를 더 움직인다. 카메라 놓기와 찍기를 한 동기 블록에서 하고, 찍는 동안 그리기 루프를 멈춘다.
6. **첫 프레임의 음수 `dt`.** 첫 `requestAnimationFrame` 시각이 시작 시각보다 이를 수 있다. 음수 단계 물리는 거기 의존하는 모든 것을 NaN 으로 만든다. `dt` 를 아래로 0 에서 자른다.
7. **지난 에셋의 레시피를 기본값으로.** 한 형태에 맞던 기법이 다른 형태에서는 새 오류를 낸다. 형태에 맞게 고른다.
8. **복잡한 형태를 스크립트로.** 부품이 많거나 알아볼 얼굴이 있는 에셋은 기본 도형 스크립트로 레퍼런스를 따라 모이지 않는다: 숫자를 아무리 돌려도 실루엣이 콘셉트에 가까워지지 않는다. 2–3바퀴 동안 가까워지지 않으면 image-to-3D 로 넘어간다 (유니코 팜 캐릭터는 SDF 스무스 유니온으로 — `unico-chibi-body.md`).
9. **생성기는 축척을 지키지 않는다.** 시트 라벨은 맞는데 형체는 축척이 아니다. 정확한 시트는 먼저 축척 맞춘 평면 눈금, 그 위에 생성, 픽셀로 재서 확인.
10. **틀린 수정 선언.** 지난번 "고쳤다"가 작동하지 않았음이 드러나면 바로 말하고 이유를 설명한다.

물리 규칙(받침 기준 감쇠, 세로, 한계, 공진, 시뮬레이션 단계)은 `references/motion-recipes.md`.
