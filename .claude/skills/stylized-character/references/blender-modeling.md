# Blender 모델

> 유니코 팜: 캐릭터에는 쓰지 않는다 (캐릭터는 SDF 코드 — `unico-chibi-body.md`). 소품·환경 에셋은 이 저장소의 `blender/build_environment.py` + `common.py` 방식이 먼저이고, 아래는 원리 참고용이다. 여기 컨테이너의 `bpy` 모듈은 glTF 내보내기는 되지만 렌더링은 안 되므로 `--preview` 대신 three.js + Playwright 캡처를 쓴다.

도우미: `scripts/blender_kit.py`. 스크립트로는 큰 형태가 적은 에셋을 만든다. 복잡한 형태는 image-to-3D 에서 가져와 여기서 정리한다: 계약서대로 크기와 축, 움직이는 부분 분리 또는 스키닝, 재질 슬롯, 데시메이트, 가중치(`set_weight_attribute`).

## 실행

```bash
blender -b --factory-startup -P tools/blender/<이름>.py -- assets/models/<이름> [--preview]
```

macOS 에서 실행 파일은 `/Applications/Blender.app/Contents/MacOS/Blender` 이고 보통 PATH 에 없다. `--preview` 는 내보내기 대신 네 각도의 `<out>_preview.png` 를 쓴다. 플래그가 없으면 AO 를 굽고 `<out>.glb` 를 쓴다.

## 스크립트 구조

1. 머리말: 무슨 에셋인지, 실행 명령, 축.
2. `blender_kit` (축, 재질, 도우미).
3. 비율 블록: 계약서를 참조하는 상수.
4. 부품을 하나씩, 각각 주석과 함께: 어떤 형태이고 왜 그렇게 만들었는지.
5. 그룹별 AO, 미리보기 또는 내보내기.
6. 예산을 보도록 마지막 줄 `CHARACTER_DONE parts=… tris=…` (`report()` 가 출력).

## 축과 부품

- 좌표는 three.js 축(x 오른쪽, y 위, z 보는 쪽)으로 쓰고 `T(x, y, z) = (x, -z, y)` 로 바꾼다.
- 움직이는 부품마다 매달린 관절(어깨, 팔꿈치, 손, 머리, 발, 매달린 것의 고리)에 중심을 둔 별도 객체 `mesh_obj(name, bm, mats, origin=<관절>)`. 그러면 장면이 다시 계산하지 않고 리그 뼈에 건다.
- 재질 이름은 칠하기 슬롯(예: `cloth`, `lining`, `metal`, `wood`). 스크립트 속 색은 미리보기용일 뿐이다.

## 만드는 기법

| 형태 | 기법 |
|---|---|
| 머리쓰개, 자루, 껍데기 | UV 구 → 구멍 내기 → 방사 방향 변위 → `solidify` → `subsurf`. 한 표면; 그래도 자기 교차는 확인 |
| 뾰족한 끝, 주름 | 원뿔을 붙이지 말고 같은 표면 일부를 밀어낸다 |
| 망토, 치마 | 윤곽으로 `lathe` → 각도 함수로 주름 → 위를 고정한 천 시뮬레이션 한 번 → `bake` → `solidify` |
| 목도리, 리본, 끈 | 두께 함수가 있는 `torus` 또는 `curve_bm` |
| 벙어리장갑, 신발, 통통한 형태 | `metaball` |
| 단단한 물건 | `box` + `bevel_all`, 불리언, 평면 셰이딩 |
| 덧댄 천, 바느질 | `patch()` 가 천 조각을 표면에 투영; 바늘땀은 적게, 한 점으로 모으지 않는다 |

필수 목록이 아니라 기법 모음이다. 에셋 형태에 맞게 고른다.

규칙:
- 옷의 아래 가장자리는 덮는 옷 안으로 끼워 넣는다. 아니면 보이는 곳에서 표면이 교차한다.
- 껍데기 두께(`solidify`)는 키의 ~1.5% 이상: 더 얇으면 가파른 주름에서 안감이 비친다.
- 얼굴 구멍이 있으면 안쪽 면은 어두운 구멍 재질, 가장자리는 자기 재질.
- 삼각형과 부품 예산은 스크립트가 아니라 계약서가 정한다.

## 변형 가중치

장면이 셰이더에서 모델 일부를 굽힌다면 가중치는 스크립트에서 계산한다: `sway` — 통째 흔들림 참여(바닥 0, 위쪽 1 가까이), `wob` — 끝 굽힘 참여(바닥 0, 끝 1). 전환은 필요해 보이는 것보다 짧게: 키 40% 에 걸친 부드러운 계단이면 눈에는 윗부분만 움직인다.

모델을 만드는 동안 가중치는 임시 UV 세트에 둔다: `solidify`, `subsurf`, `bake` 를 견딘다. 새 면은 가장 가까운 정점에서 가중치를 복사한다. 내보내기 전에 정점 속성 `_wob`, `_sway` 로 옮긴다(`weights_to_attributes()`): glTF 내보내기는 재질이 읽지 않는 UV 세트를 버린다. 가져온 메시는 UV 단계 없이 바로 속성을 쓴다(`set_weight_attribute`).

## 정점 색에 AO

`bake_ao(groups)` 가 AO 를 정점 색에 굽는다. 따로 움직이는 그룹(팔, 손에 든 물건)은 나머지 몸 없이 굽는다. 아니면 든 팔 밑에 그림자가 남는다.
